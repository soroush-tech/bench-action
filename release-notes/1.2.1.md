## bench-action@1.2.1

Fixes the 1.2.0 summary table, which showed every bench file as `_no results_` with no
ratios. Upgrade from 1.2.0; workflows need no change.

### Fixed

- 1.2.0 was released with the sandbox of `@soroush.tech/bench` **2.1.0**, which does not
  know `--json-file`. The runs wrote no JSON, so the summary had nothing to read. The
  sandbox is now vendored from bench **2.3.0**.
- The gate was not affected: pass and fail were decided correctly in 1.2.0, and the
  per-file tables were complete.

### Internal

- `npm run vendor` now refuses a pinned bench whose harness has no `--json-file`
  support, so a release can't ship this mismatch again.
